# Ecommerce-Sales-Dataset
Exploratory and Cleaned Ecommerce Kaggle Dataset (Python/SQL)

Ecommerce Sales Data Analysis

## Overview

This project analyzes an ecommerce sales dataset to identify sales trends, top-performing products and categories, customer purchasing behavior, payment preferences, and delivery performance.

The goal is to turn raw, messy order data into clear business insights that can help improve revenue and customer experience.

## Dataset

The dataset contains order-level ecommerce data, including:
Customer and order IDs
Order dates
Products and categories
Quantity, price, total
Payment method
Delivery status

## Tools Used

Python (Pandas): Data cleaning and exploratory data analysis (EDA)

MySQL: Storing cleaned data and answering business questions with SQL queries

Power BI: Creating a sales dashboard

Jupyter Notebook: Writing and running the Python analysis

## Project Steps

Loaded the raw ecommerce dataset into Python.

Inspected the data for missing values, duplicates, incorrect data types, and inconsistent text values.

Cleaned the dataset by standardizing column names, fixing category values, converting dates and numeric columns, removing duplicates, and handling invalid entries.

Performed exploratory data analysis to understand sales, products, customers, and order statuses.

Exported the cleaned dataset to MySQL.

Wrote SQL queries to analyze top customers, revenue by category, payment methods, and order-status percentages.

Built a Power BI dashboard to communicate the findings visually.

Created a project report with insights and recommendations.

## Business Questions

Which products and categories generate the most revenue?

How do sales change over time?

Which customers spend the most and place the most orders?

Which payment methods are used most often?

What percentage of orders are delivered, processing, cancelled, shipped, or returned?

## Dashboard

The Power BI dashboard includes:

Total revenue, total orders, average order value, and delivery percentage

Top products by revenue

Order status breakdown

Payment method usage

Top customers by total spending 

## Results

The analysis helps identify the products, categories, and customers that contribute the most to sales. It also highlights customer payment preferences.
